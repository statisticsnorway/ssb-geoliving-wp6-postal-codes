## Background
Postal codes in Europe have evolved as a key tool for organizing mail delivery and, more recently, for integrating data and generating statistics. The first systematic postal codes appeared in Ukraine (then part of the Russian Empire) in 1932 but were soon abandoned. Germany introduced one of the first modern postal code systems in 1941, followed by other countries after World War II. By the 1960s and 1970s, most European nations had implemented structured postal code systems to improve mail efficiency.

Beyond mail services, postal codes have become essential for data integration and geographic analysis. They are widely used in demographics, market research, healthcare planning, and regional statistics. Since they correspond to geographic areas, they enable the linking of diverse datasets, such as income levels, population density, and infrastructure access. However, challenges exist, as postal code areas vary in size and structure across countries, sometimes making direct comparisons difficult. Despite this, they remain a valuable tool for spatial analysis and policymaking.

## Objectives
In this work package we plan to explore possibilities of extending a time series of post codes as long back in time as possible. Statistics Norway have previously worked on this subject. The goal and approach then were to set up an API for code list and remastering polygon geodata back to 1968, the year the postal area code system was established in Norway.
This approach turned out to be time consuming, and we plan this time to focus more on extending the time series using phonetical and spatial analysis, to establish the code lists as a look up tool and geodata as a point layer.

By using Norway Post’s postal database, we plan to prolong and geo-reference a postal look-up database for the period before 1968. We expect quality assessments to be done by cross examining with available historical data and voluntary work by postal historians.
Statistics Norway´s geoportal is under development, and we expect the portal to be open for automatic uploads of time versions of geodata in the near future. This will make implementation of services as WMS and WFS much more efficient.

## Expected outcomes and deliveries
Expected outcomes are inventories of available sources of postal codes with quality assessments, and development of methods for enhanced georeferencing. These outcomes will be parts of deliveries of this work package. Where relevant, outcomes from this WP be included into deliveries in WP2.
